# Бот для разгона депозита на Binance Futures

Бот торгует бессрочными фьючерсами USDⓈ-M на Binance с плечом и
сложным процентом. Цель — за короткий срок увеличить небольшой депозит
в несколько раз. Как только цель достигнута или пробит лимит убытка, бот
останавливается.

> ⚠️ **Важно.** Разгон депозита с плечом — это высокий риск. Большинство
> таких попыток заканчиваются потерей депозита. Вкладывайте только те деньги,
> которые готовы потерять полностью. Сначала прогоните бэктест, потом режим
> `paper` или `testnet`, и только после этого `live`. Прибыль никто не гарантирует.

## Стратегия

* **Вход.** Быстрая EMA (9) пересекает медленную (21) на закрытой свече.
  Фильтр по RSI (14): для лонга 50–70, для шорта 30–50. Так бот входит
  по импульсу, но не на перекупленности или перепроданности.
* **Стоп-лосс.** 1.5 × ATR от входа.
* **Тейк-профит.** 2 стопа (RR 1:2). Средняя прибыль вдвое больше среднего
  убытка, поэтому стратегия может быть в плюсе даже при винрейте около 35–40%.
* **Сложный процент.** В каждой сделке риск равен фиксированному % (по
  умолчанию 2%) от *текущего* депозита. После прибыльных сделок позиции
  растут, после убыточных уменьшаются.
* **Условия остановки:**
  * депозит вырос на `TARGET_PROFIT_PCT` (по умолчанию +100%, то есть x2);
  * просадка от старта достигла `MAX_DRAWDOWN_PCT` (по умолчанию 30%);
  * подряд `MAX_CONSECUTIVE_LOSSES` убыточных сделок.

На бирже бот выставляет стоп и тейк сразу после входа. Если поставить стоп
не удалось, бот тут же закрывает позицию.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # заполните параметры
```

## Режимы (`MODE` в `.env`)

| Режим     | Что делает |
|-----------|------------|
| `paper`   | Берёт реальные котировки и симулирует сделки локально. Ключи не нужны |
| `testnet` | Отправляет ордера на [testnet.binancefuture.com](https://testnet.binancefuture.com) |
| `demo`    | Работает через демо-трейдинг Binance (demo.binance.com) |
| `live`    | Торгует **реальными деньгами** |

API-ключу для `live` достаточно права *Enable Futures*. **Не включайте
вывод средств** и ограничьте ключ по IP.

## Запуск

```bash
# Бэктест на истории (публичные данные, ключи не нужны)
python -m bot.backtest --days 30
python -m bot.backtest --days 90 --no-guard   # весь период, без остановки по цели или просадке

# Бот
python -m bot.main

# Тесты
python -m pytest -q
```

Лог работы пишется в консоль и в `bot.log`. Если остановить бот через Ctrl+C,
открытая позиция на бирже **не закрывается**: стоп и тейк продолжают работать.

## Настройка

Все параметры задаются в `.env` (описание в `.env.example`). Что влияет
на «агрессивность» разгона:

* `RISK_PER_TRADE_PCT` — главный параметр. 2% считается умеренным риском,
  5% и выше — агрессивным: 10 убыточных сделок подряд при 5% оставляют
  от депозита около 60%.
* `LEVERAGE` — только ограничивает максимальный объём позиции. Размер
  риска задаёт стоп и `RISK_PER_TRADE_PCT`, а не плечо.
* `TIMEFRAME` — на младших таймфреймах сделок больше, но и шума
  с комиссиями тоже больше.

## Структура

```
bot/
  indicators.py  EMA, RSI, ATR
  strategy.py    генерация сигналов
  risk.py        размер позиции, условия остановки
  broker.py      paper-симуляция и Binance через ccxt
  backtest.py    бэктест на истории
  main.py        основной цикл
tests/           юнит-тесты
```
