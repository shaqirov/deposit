# Торговый бот для Binance Futures

Бот торгует бессрочными фьючерсами USDⓈ-M на Binance. Основная стратегия —
пробой по направлению тренда (`breakout`) на 4-часовом графике со строгим
риск-менеджментом.

> ⚠️ **Важно.** Торговля фьючерсами с плечом — это риск потерять депозит.
> Прибыль никто не гарантирует. Порядок проверки: бэктест → `paper` →
> `testnet` → `live` с небольшой суммой.

## Стратегии

Стратегия выбирается параметром `STRATEGY` в `.env`.

| `STRATEGY` | Идея | Тейк |
|---|---|---|
| `breakout` (по умолчанию) | Пробой максимума или минимума 20 свечей по направлению EMA 200 | 2 стопа |
| `trend_pullback` | Тренд: цена выше 200-дневной SMA и максимумы растут (для шорта зеркально). Вход на откате: свеча коснулась EMA 20 и закрылась обратно в сторону тренда. Против тренда не торгует | 2 стопа |
| `ema_cross` | Импульс: быстрая EMA (9) пересекает медленную (21), фильтр RSI | 2 стопа |
| `mean_reversion` | Возврат к среднему от полос Боллинджера при экстремальном RSI | средняя линия |

Для `trend_pullback` стоп ставится за локальным минимумом последних 10 свечей
(для шорта — за максимумом) с запасом 0.5 ATR. Для остальных стратегий стоп
равен 1.5 ATR.

## Риск-менеджмент

* **Риск на сделку 1%** от текущего депозита (`RISK_PER_TRADE_PCT`). Размер
  позиции считается от расстояния до стопа: при срабатывании стопа теряется
  ровно этот процент. 10 убытков подряд оставляют около 90% депозита.
* **Плечо до 3x** (`LEVERAGE`). Оно только ограничивает максимальный объём
  позиции. Маржа изолированная.
* **Стоп-лосс и тейк-профит** выставляются на бирже сразу после входа. Если
  стоп поставить не удалось, бот тут же закрывает позицию.
* **Перерыв после 3 убытков подряд** на 48 часов (`MAX_CONSECUTIVE_LOSSES`,
  `PAUSE_HOURS`). Если указать `PAUSE_HOURS=0`, бот вместо перерыва
  останавливается.
* **Аварийная остановка** при просадке 25% от старта (`MAX_DRAWDOWN_PCT`) и при
  достижении цели (`TARGET_PROFIT_PCT`, 0 — без цели).
* **Фильтр funding.** Бот не открывает лонг, если ставка финансирования выше
  0.05% за 8 часов (лонги перегреты), и шорт, если ниже −0.05%
  (`MAX_FUNDING_PCT`, 0 — фильтр выключен). Бэктест учитывает историю ставок.
* **Новости.** В окне от 12 часов до и до 4 часов после события из файла
  `news.txt` новые сделки не открываются. Уже открытые позиции бот не трогает.
  Даты событий нужно вносить в файл самостоятельно, ссылки на официальные
  календари есть в самом файле.
* **Журнал сделок.** Бот записывает каждую закрытую сделку в `journal.csv`.
  Бэктест сохраняет сделки в CSV с параметром `--journal`. Файл открывается
  в Excel.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # на Windows: copy .env.example .env
```

## Режимы (`MODE` в `.env`)

| Режим     | Что делает |
|-----------|------------|
| `paper`   | Берёт реальные котировки и симулирует сделки локально. Ключи не нужны |
| `testnet` | Отправляет ордера на [testnet.binancefuture.com](https://testnet.binancefuture.com) |
| `demo`    | Работает через демо-трейдинг Binance (demo.binance.com) |
| `live`    | Торгует **реальными деньгами** |

API-ключу для `live` достаточно права *Enable Futures*. **Не включайте
вывод средств** и ограничьте ключ по IP.

## Запуск

```bash
# Бэктест текущих настроек из .env (публичные данные, ключи не нужны)
python -m bot.backtest --days 730
python -m bot.backtest --days 730 --no-guard --journal trades.csv

# Сравнение стратегий: по умолчанию BTC, ETH на 4h и 1d за 4 года
python -m bot.compare
python -m bot.compare --symbols BTC,ETH,SOL --timeframes 4h --strategies trend_pullback

# Бот
python -m bot.main

# Тесты
python -m pytest -q
```

Бэктест и сравнение показывают результат отдельно для первой и второй
половины периода. Если стратегия заработала только на одной половине,
скорее всего, ей просто повезло.

200-дневной SMA на 4h нужно 1200 свечей истории, на это уходит первая
часть периода. Поэтому для `trend_pullback` берите не меньше 2 лет истории.

Лог работы пишется в консоль и в `bot.log`. Если остановить бот через Ctrl+C,
открытая позиция на бирже **не закрывается**: стоп и тейк продолжают работать.

## Запуск на сервере

Нужен сервер с Ubuntu 22.04/24.04 в стране, откуда Binance доступен (не США).
Код скачивается из GitHub в `/opt/deposit`, затем:

```bash
sudo bash /opt/deposit/deploy/install.sh   # установка и автозапуск
sudo journalctl -u deposit-bot -f          # лог в реальном времени
sudo nano /opt/deposit/.env                # настройки
sudo systemctl restart deposit-bot         # перезапуск после смены настроек
sudo bash /opt/deposit/deploy/update.sh    # обновление кода из GitHub
```

Бот работает как сервис systemd: запускается сам после перезагрузки сервера
и перезапускается при сбое.

## Структура

```

  indicators.py  SMA, EMA, RSI, ATR
  strategy.py    стратегии и фильтр funding
  risk.py        размер позиции, перерывы, условия остановки
  broker.py      paper-симуляция и Binance через ccxt
  news.py        окна вокруг новостей
  journal.py     журнал сделок в CSV
  backtest.py    бэктест на истории (со ставками funding)
  compare.py     сравнение стратегий, монет и таймфреймов
  main.py        основной цикл
deploy/          установка на сервер и сервис systemd
news.txt         даты важных событий
tests/           юнит-тесты
```
